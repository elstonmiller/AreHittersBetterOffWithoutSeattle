# AreHittersBetterOffWithoutSeattle
Statistical analysis in R comparing MLB hitters’ performance with the Seattle Mariners versus other organizations.

An R-based statistical analysis investigating whether MLB hitters perform differently while playing for the Seattle Mariners compared with other organizations. Using player data from 2010–2025, the project compares five offensive metrics and uses Welch Two-Sample t-tests to identify statistically significant differences.

Tools: R · ggplot2 · dplyr · Statistical Hypothesis Testing · Data Visualization

Key Finding: Mariners hitters showed significantly lower on-base percentages and higher strikeout rates, while differences in OPS+, slugging percentage, and walk rate were not statistically significant.
